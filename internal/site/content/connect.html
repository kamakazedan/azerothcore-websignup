If something goes wrong

Your change to realmlist.wtf doesn't stick
Windows guards the Program Files folder, so edits there can fail or be ignored. Move the whole game folder somewhere like C:\Games and edit it there.
The game can't connect at all
Check that realmlist.wtf holds only the one line above, and that the realm shows as online at the top of this page.
“The information you have entered is not valid”
The username or password is wrong. Use your account's username, not your email address or a character's name.
The launcher wants to update the game
Close it and start Wow.exe directly. This server needs the game exactly as it was in {{GAME_VERSION}}.
Odd item names or missing icons
Close the game and delete the Cache folder inside the game folder. The game rebuilds it.
The download ends in .7z
It's a 7-Zip archive. Open it with 7-Zip on Windows, or The Unarchiver on a Mac.
Playing on Linux or a Mac
The Windows client runs well under Wine, Lutris or CrossOver.
