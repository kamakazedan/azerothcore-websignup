How to connect

  1. Get the game

    {{- if .Cfg.DownloadURL}}

    Download our ready-to-play Wrath of the Lich King client, version {{.Cfg.GameVersion}}, and unpack it somewhere outside Program Files.{{if .Cfg.ClientHasRealmlist}} It already points at {{.Cfg.SiteName}}, so you can skip straight to logging in.{{end}}

    Download the client

    {{- else}}

    You need the Wrath of the Lich King client, version {{.Cfg.GameVersion}}. Other versions can't connect.

    {{- end}}

  2. Set your realmlist

    {{- if and .Cfg.DownloadURL .Cfg.ClientHasRealmlist}}

    Only if you're using your own copy of the game: our client is already set.

    {{- end}} {{- if .Cfg.Realmlist}}

    Open realmlist.wtf in Notepad. It's in the game folder, under Data/enUS or, on a UK client, Data/enGB. Replace everything in it with this line:

    {{template "realmlist" (dict "ID" "realmlist" "Line" .Cfg.Realmlist "Asset" .Asset)}} {{- else}}

    Ask the server's admin for the realmlist address, and put it in Data/enUS/realmlist.wtf in the game folder.

    {{- end}}

  3. Log in

    Start Wow.exe from the game folder, not the launcher, and log in with the username and password you chose here.
